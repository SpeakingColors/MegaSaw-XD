# MegaSaw XD

<img src="assets/icon.svg" width="96" align="right" alt="icon">

Planned: a bigger supersaw oscillator for the KORG minilogue xd, built on what we learned making [HyperSaw](https://github.com/SpeakingColors/hypersaw-xd) and [SawWiden](https://github.com/SpeakingColors/sawwiden-xd).

## Status
Planning. No build yet. Free and open source.

## Goals
- More voices per layer than HyperSaw, still light enough for the xd's CPU budget
- Same JP-8000 style detune curve, with a stereo-friendly spread idea (the xd output is mono, so width comes from the SawWiden FX)
- Layer waveforms to choose from: supersaw, square, pulses, glass, vocal "Ah"
- Made for trance, hardstyle and UK hardcore leads
